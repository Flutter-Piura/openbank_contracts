# Política de seguridad

OpenBank solo admite datos ficticios. No publiques vulnerabilidades en issues; usa:

<https://github.com/Flutter-Piura/openbank_contracts/security/advisories/new>

Incluye impacto, reproducción, versiones y mitigación. No pruebes hallazgos con sistemas, credenciales o datos reales. Antes de `1.0.0` se mantiene `main` y el release preliminar más reciente.
